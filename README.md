# CS 330: Computational Graphics and Visualization

## Project Overview

This repository contains my final project for CS 330. The project is a low-polygon 3D representation of a clothing rack based on a photograph of a real-world scene. I used C++, OpenGL, and Visual Studio 2022 to model the rack, shelves, folded clothing, lamp, walls, and floor. The finished scene includes textured surfaces, multiple light sources, material properties, interactive camera controls, and perspective and orthographic views.

## How do I approach designing software?

This project taught me to begin the design process by breaking a larger idea into smaller and more manageable parts. I studied my reference photograph and identified the basic shapes that could represent each part of the clothing rack. I used boxes for the square metal frame and wooden shelves, cylinders for the clothing rails and parts of the lamp, and planes for the floor and wall. I also learned how scaling, rotation, and translation work together to position objects accurately in a 3D environment.

My design process developed gradually throughout the course milestones. I first created the main structure, then added camera movement, textures, materials, lighting, and smaller details. I compared the rendered scene with the reference photograph after each change and adjusted objects that looked incorrectly sized or positioned. I also experimented with additional clothing and storage items, but removed or revised elements that made the scene appear crowded. I can use this same approach in future projects by dividing complex problems into smaller components, planning how those components will work together, and testing each design decision before moving forward.

## How do I approach developing programs?

One of the most useful development strategies I practiced during this project was making small changes and testing them frequently. Instead of changing several parts of the scene at once, I adjusted an object’s scale, rotation, or position and then built and ran the program to examine the result. This made it easier to identify the cause of problems such as clipping, incorrect proportions, stretched textures, or objects facing the wrong direction. I also used the provided transformation, texture, and material functions throughout the scene so that the code remained consistent and organized.

Iteration was important during every milestone. I began by creating the basic shapes and structure of the clothing rack. Later milestones added camera navigation, texture mapping, materials, lighting, and projection controls. Each new feature required me to review earlier work and make adjustments so that the complete scene continued to function correctly. By the end of the course, my development approach had evolved from focusing on whether a single shape appeared correctly to considering how geometry, lighting, textures, camera movement, and user input all work together. This process showed me the value of building programs gradually, testing often, and improving earlier work as new requirements are introduced.
